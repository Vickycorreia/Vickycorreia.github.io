# Cardboard Rafale: content sources

The owner's latest message and supplied `Rafale.zip` supersede the earlier description: **the build is still in progress, and landing gear is a future addition**. The earlier copy saying that gear was already built has been corrected on both project pages and the home cards. In-progress status also appears on the orbital destination, launch selector, TARGET/arrival and the other projects' navigation cards.

Confirmed directly by the owner:

- Entirely independent construction, without help, using reclaimed cardboard.
- Measurements from a reference photograph, with personal working plans and annotations.
- A craft knife and a hot glue gun are the construction tools.
- The current aircraft includes its wings, cockpit, nose, main structure and visible rear details.
- Remaining work: smooth the fuselage, build the landing gear, add decorative model missiles and harmonise the final finish in grey tones.
- Electronic deployment of the gear is a possible extension, not a completed feature.
- Learning includes patience, care, structure, managing a project and aviation; this hands-on project matters personally to the owner.
