01The objective

Build a system that can encode and decode Morse messages on an STM32 microcontroller. Alongside the message conversion, the project includes a defined message format and error checking.

02The approach

The embedded implementation uses C on STM32. Morse encoding and decoding are paired with a message format and CRC-8, bringing message representation and integrity checking into the same system.

03My contribution

I built the Morse message encoder and decoder. The project brought together embedded programming, a defined communication format and CRC-8 error checking.
